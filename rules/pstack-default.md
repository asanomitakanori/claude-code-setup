# Default pstack workflow

For substantive engineering work, use pstack by default. Read the installed pstack poteto-mode SKILL.md at the start of the task, choose the applicable playbook, and follow its relevant steps. Use standalone pstack skills for their matching tasks. For a trivial question or one-step check, use judgment and avoid unnecessary ceremony.

pstack is installed under `~/.claude/plugins/cache/<marketplace>/pstack/<version>/`; use the highest version and resolve bundled skill paths relative to it. Use the host's available tools and models; do not assume Claude-specific agent types or model names exist in Codex. Higher-priority instructions, the user's explicit requests, and project contracts take precedence, including any restrictions on delegation, approval, external writes, or deployment.
